# 📋 Отчёт монтажника

Веб-форма для ежедневных отчётов о монтажных работах на объектах.
Данные уходят в Google Таблицу через Google Apps Script, оттуда —
в сводки «Выполнение» и «ОЖР» по каждому объекту.

Поддерживается **несколько объектов** одновременно, каждый со
своим набором листов и своим логом отклонённых запросов.

---

## 🎯 Что делает

### Для монтажника (форма)

1. Заполняет шапку: **Дата, Имя Фамилия, Объект**.
2. Заполняет материалы (Монтаж / Демонтаж) и/или другие работы.
3. Жмёт **«Добавить всё в журнал»** — данные попадают во
   внутренний журнал формы, где дубли по одинаковому месту
   объединяются.
4. Жмёт **«Отправить отчёт»** → экран проверки → отправка →
   галочка 👍.
5. Все строки уходят одним пакетом в Google Таблицу —
   в лист «Отчеты "…"» нужного объекта.

Внутри формы:

- валидация имени (ровно 2 слова), даты (не старше N дней), объекта;
- оффлайн-детект: без сети кнопка «Отправить» заблокирована;
- черновик журнала в localStorage (не потеряется при закрытии вкладки);
- экран проверки перед отправкой;
- светлая / тёмная тема.

### Для прораба (таблица)

В таблице появляется меню **📋 Журналы** с подменю по каждому
объекту. В каждом подменю:

**Построение отчётов**

- 📊 Выполнение — за сегодня
- 📊 Выполнение — за другой день
- 📘 ОЖР — за сегодня
- 📘 ОЖР — за другой день

**Навигация**

- 📄 Открыть «Отчеты»
- 📄 Открыть «Отклонённые»
- 📂 Открыть «Выполнение»
- 📂 Открыть «ОЖР»

**Очистка**

- 🗑 Очистить «Отчеты»
- 🗑 Очистить «Отклонённые»
- 🗑 Очистить «Выполнение»
- 🗑 Очистить «ОЖР»

### Google Apps Script (бэкенд) — 2 файла

| Файл | Назначение |
|------|-----------|
| `Code.js` | `doPost` + меню + сборка «Выполнение» и «ОЖР» |
| `coords.js` | Справочник координат помещений |

> В Apps Script файлы могут иметь расширение `.gs` или `.js` —
> работают одинаково.

### Google Таблица (хранилище)

Листы создаются автоматически при первом запуске.
Для каждого объекта — свой набор из четырёх листов.

| Лист | Что там |
|------|--------|
| `Отчеты "<объект>"` | Все строки из формы (сырые данные) |
| `Отклонённые "<объект>"` | Лог отклонённых запросов |
| `Выполнение "<объект>"` | Сводка по дням (собирается из меню) |
| `ОЖР "<объект>"` | Итоговый журнал работ (собирается из меню) |

Плюс один общий fallback-лист `Отклонённые` — для случаев, когда
объект из формы не распознан.

## 📊 Формат данных

### Лист «Отчеты "…"» — сырые данные из формы

| A | B | C | D | E | F | G | H | I | J | K |
|---|---|---|---|---|---|---|---|---|---|---|
| Объект | Дата | Имя | Этаж | Помещение | Тип работ | Система | Материал | Ед.изм. | Кол-во | timestamp |

- **Дата** — формат `ДД.ММ.ГГГГ`, хранится как настоящая дата.
- **Кол-во, Помещение, Этаж** — текстовый формат, чтобы числа
  вроде `1-2` не превращались в дату автоматически.
- Помещения сохраняются **без координат** (`1, 2, к5`) —
  координаты применяются только в листе «Выполнение».

### Лист «Выполнение "…"» — сводка по дням

| A | B | C | D | E | F | G | H | I | J |
|---|---|---|---|---|---|---|---|---|---|
| Дата | Наименование работ | Этаж | Пом. № | Тип работ | Система | Материалы | Ед.изм | Кол-во | Кол-во работников |

- **A, B, J** объединены на весь день (merge).
- **B** — текст-сводка вида:
  `Монтаж кабельных линий для систем АПС, СОУЭ. 1 этаж: 8 (Р-С/1-2), 47 (Е-Ж/4-5). 2 этаж: 11 (В-Д/2-4).`
- **J** — фактическое количество работников за день
  (все уникальные имена, независимо от того, попали их работы
  в строки или нет).

**Что не попадает в «Выполнение»:**

- Демонтаж — целиком;
- Затяжка кабеля в гофру;
- Установка крышек кабель-канала;
- Разметка кабельных трасс;
- Штукатурка;
- Тура (монтаж/демонтаж);
- Страховка лестницы;
- Наставничество.

### Лист «ОЖР "…"» — основной журнал работ

| A | B | C | D | E |
|---|---|---|---|---|
| пусто | Дата | пусто | Наименование работ | ФИО |

- **Столбец D** — сводка за день + строка
  `При выполнении работ применены: <материалы>.`
  Заполняется **только монтаж** (без демонтажа и других работ).
  Выравнивание по левому краю, перенос по словам.
- **Столбец E** — заполняется вручную.
- Всё остальное — по центру.

## ⚙️ Настройка

### 1. Бэкенд (Apps Script)

1. Открыть Google Таблицу → **Расширения → Apps Script**.
2. Создать **два** файла:
   - `Code.js` — основной;
   - `coords.js` — справочник координат.
3. Вставить код из репозитория.
4. Сохранить. Развернуть как **веб-приложение**
   (запуск от имени: **Я**, доступ: **Все**).
5. Скопировать URL развёртывания.
