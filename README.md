📋 Отчёт монтажника + Фотофиксация
Этот проект состоит из двух частей: Сайт (то, что видят монтажники) и Скрипт (то, что работает внутри Google).

📁 Шаг 1: Куда какие файлы класть?
Условно у нас есть две папки. Не перепутай их!

🌐 Часть 1: Файлы для сайта (GitHub)
Эти файлы ты загружаешь в свой репозиторий на GitHub (или на любой хостинг). Они открываются в браузере.

index.html — основная форма (отчет).

script.js — мозги основной формы.

photos.html — страница загрузки фото.

photos.js — мозги страницы с фото (сжатие картинок и отправка).

style.css — красота (стили для обеих страниц).

⚙️ Часть 2: Файлы для Google Apps Script
Эти файлы НЕ кидаются на GitHub. Их нужно вставить в редактор скриптов, который открывается из твоей Google Таблицы.

Code.gs — принимает отчеты и собирает листы (Выполнение, ОЖР).

photos.gs — принимает фото и раскладывает их по папкам на Google Диске.

coords.gs — справочник координат помещений (для листа Выполнение).

appsscript.json — настройки прав (чтобы скрипт мог писать на Диск).

🚀 Шаг 2: Как это всё запустить? (Инструкция)
Если делаешь с нуля, иди строго по шагам:

1. Настройка Google (Таблица и Скрипты)
Создай новую Google Таблицу.

В таблице нажми: Расширения → Apps Script.

Создай там 3 файла с кодом: Code.gs, photos.gs, coords.gs. Скопируй в них код.

Слева нажми на иконку ⚙️ (Настройки проекта). Поставь галочку «Показывать файл манифеста appsscript.json».

В появившемся файле appsscript.json вставь код, который лежит в этом репозитории (там прописаны права на Google Диск).

Сохрани всё (Ctrl+S).

2. Выдача прав и Развертывание
В Apps Script выбери функцию testDrivePermissions (она в photos.gs) и нажми ▶ Выполнить.

Google попросит разрешения. Жми «Разрешить» (Дополнительные настройки → Перейти на ... небезопасно). В журнале должно появиться ✅ УСПЕХ.

Сверху справа нажми Развернуть → Новое развертывание.

Тип: Веб-приложение. Запуск от имени: Я. Доступ: Все.

Нажми «Развернуть» и скопируй длинную ссылку (она заканчивается на /exec).

3. Связывание сайта и скрипта
Открой файл script.js (на GitHub) и найди строку const API_URL = '...'.

Вставь туда ссылку, которую скопировал в пункте 2.5.

То же самое сделай в файле photos.js.

4. Настройка папок на Диске
Создай на Google Диске папку для объекта (например, Ларинская гимназия / Фотофиксация...).

Открой эту папку в браузере. В адресной строке найди ID (набор букв и цифр после /folders/).

Открой photos.gs и вставь этот ID в PHOTO_ROOT_BY_OBJECT.

Сохрани и не забудь сделать Новую версию развертывания (Развернуть → Управление развертываниями → ✏️ → Новая версия).

📸 Как фото выглядят на Диске?
Если всё работает, то после отправки форма сама создаст такую структуру:

📁 Иван Петров (имя монтажника)

📁 17.10.2026 (дата)

📁 Помещения / 2 этаж / 45 / 45 До работ 1.jpg

📁 Проходки / 2-3 этаж / 3-4 / 3-4 До сверления 1.jpg

📁 Оборудование / BIAD / 2.45 / 2.45 (1).jpg

💡 Важно помнить
После любых изменений в файлах .gs (Apps Script) нужно обязательно нажимать:
Развернуть → Управление развертываниями → ✏️ (карандаш) → Версия: Новая версия → Развернуть.
Иначе форма продолжит отправлять данные по старому коду.
