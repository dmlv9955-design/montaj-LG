# 📋 Отчет монтажника

Веб-форма для заполнения ежедневных отчётов о монтажных работах. Данные уходят в Google Таблицу через Google Apps Script. Оптимизирована под телефон: крупные поля, тёмная тема, валидация на лету, зависимые поля, журнал записей и локальное объединение дублей.

---

## 🎯 Что делает

Монтажник открывает форму, заполняет шапку (дата, имя, объект, корпус), добавляет одну или несколько записей в **журнал** (каждая запись — это этаж + помещение + тип работ + материалы), при необходимости — «Другие работы» (заделка поверхностей, наставничество). Затем жмёт «Отправить отчёт» — все записи журнала уходят в Google Таблицу одним пакетом.

Один отчёт = **N записей журнала**, каждая запись = **M строк** (по числу израсходованных материалов).

## 🛠️ Стек

| Слой | Технология |
|------|-----------|
| Разметка | HTML5 |
| Стили | CSS3 (переменные, тёмная тема) |
| Логика | Vanilla JS (без фреймворков) |
| Бэкенд | Google Apps Script (`doPost`) |
| Хранилище | Google Sheets |

Никаких сборщиков, npm и зависимостей — три файла, работают из коробки.
