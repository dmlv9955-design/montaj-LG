# 📋 Отчёт монтажника

Веб-форма для заполнения ежедневных отчётов о монтажных работах на объектах
**«Ларинская гимназия»** и **«ЖЕДЕПОМ»**. Данные уходят в Google Таблицу через
Google Apps Script. Дополнительно — автоматическая сводка по дням
(лист **«Выполнение "Ларинская"»**) с координатами помещений.

---

## 🎯 Что делает

### Для монтажника (форма)

1. Заполняет шапку: **Дата, Имя Фамилия, Объект**.
2. Заполняет материалы (Монтаж / Демонтаж) и/или доп. работы.
3. Жмёт **«Добавить всё в журнал»** — данные попадают во внутренний журнал формы, где дубли объединяются.
4. Жмёт **«Отправить отчёт»** → проверка, отправка, галочка 👍.
5. Все строки уходят одним пакетом в Google Таблицу.

### Для прораба (таблица)

- Открывает таблицу → меню **«Выполнение»** → **«Сформировать за сегодня»** или **«Сформировать за другой день»**.
- Скрипт собирает лист **«Выполнение "Ларинская"»**: одна строка-шапка на день (дата + сводка + количество работников) + строки-разбивка по материалам.

| Файл | Назначение |
|------|-----------|
| `index.html` | Разметка формы |
| `script.js` | Вся логика формы (валидация, журнал, отправка) |

| Файл | Назначение |
|------|-----------|
| `Код.gs` | Приём отчётов (`doPost`) + сборка листа «Выполнение» |

| Лист | Что там |
|------|--------|

| **Выполнение "Ларинская"** | Сводка по дням (собирается из меню) |

## 🔄 Формат данных

### Что уходит из формы в «Отчеты»

| A | B | C | D | E | F | G | H | I | J | K |
|---|---|---|---|---|---|---|---|---|---|---|
| Объект | Дата | Имя | Этаж | Помещение | Тип работ | Система | Материал | Ед.изм. | Кол-во | timestamp |

**Помещения — без координат** (`1, 2, к5`). Координаты применяются только в листе «Выполнение».

### Что собирает лист «Выполнение»

| A | B | C | D | E | F | G | H | I | J |
|---|---|---|---|---|---|---|---|---|---|
| Дата | Наименование работ | Этаж | Пом. № | Тип работ | Система | Материалы | Ед.изм | Кол-во | Кол-во работников |

- **A, B, J** — объединены по всему дню (merge).
- **B** — сводка вида: `Монтаж кабельных линий для систем АПС, СОУЭ. 1 этаж: 8 (Р-С/1-2), 47 (Е-Ж/4-5). 2 этаж: 11 (В-Д/2-4).`
- **J** — количество уникальных имён за день.

## ⚙️ Настройка

### 1. Бэкенд (Apps Script)

1. Открыть таблицу → **Расширения → Apps Script**.
2. Создать **два** файла:
   - `Код.gs` — основной;
   - `coords.gs` — справочник координат.
3. Вставить код из репозитория.
4. Сохранить. Развернуть как **веб-приложение** (доступ: все).
5. Скопировать URL развёртывания.

### 2. Фронтенд

1. В `script.js` указать `API_URL = '...'` (URL из п. 4 бэкенда).
2. Задеплоить на любой статический хостинг (GitHub Pages, Netlify, Vercel).

### 3. Таблица

Создать три листа (или они создадутся автоматически при первом запуске):

- `Отчеты "Ларинская"`
- `Отклонённые`
- `Выполнение "Ларинская"`

Меню **«Выполнение»** появляется при `onOpen` автоматически после перезагрузки страницы таблицы.

## 🧩 Как менять данные

### Добавить/изменить материал (в форме)

`script.js` → массив `MATERIALS`.

### Добавить/изменить доп. работу

`script.js` → массив `LOCATION_WORKS`.

### Изменить справочник координат

`coords.gs` → объект `ROOM_COORDS`. Формат:

```javascript
'Ларинская гимназия': {
  'Чердак': { '1': 'В-Е/1-5', ... },         // без этажа
  'Основное здание': {
    '1': { '1': 'И-К/2-4', ... },            // 1 этаж
    '2': { '1': 'И-М/1-2', ... }             // 2 этаж
  },
  'Крыло мастерских': { ... }
}
