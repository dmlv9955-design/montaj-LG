# 📋 Отчет монтажника

Веб-форма для заполнения ежедневных отчётов о монтажных работах. Данные уходят в Google Таблицу через Google Apps Script. Оптимизирована под телефон: крупные поля, тёмная тема, валидация на лету, зависимые поля, накопительный журнал записей и локальное объединение дублей.

---

## 🎯 Что делает

Монтажник открывает форму, заполняет шапку (дата, имя, объект, корпус), затем:

- добавляет одну или несколько записей в **«Основные работы»** (этаж + помещение + тип работ + материалы);
- при необходимости заполняет любые из **«Дополнительных работ»**: штукатурка, тура, бурение, вата, герметик, бирки, расключение (каждая — с корпусом, этажом, помещениями и количеством) и наставничество (имя ученика + часы);
- жмёт «Добавить в журнал» — всё уходит в общий журнал, где дубли объединяются;
- в конце жмёт «Отправить отчёт» — все записи журнала уходят в Google Таблицу одним пакетом.

Один отчёт = **N записей журнала**, каждая запись = **M строк** в таблице (по числу израсходованных материалов).

## 🛠️ Стек

| Слой | Технология |
|------|-----------|
| Разметка | HTML5 |
| Стили | CSS3 (переменные, тёмная тема) |
| Логика | Vanilla JS (без фреймворков) |
| Бэкенд | Google Apps Script (`doPost`) |
| Хранилище | Google Sheets |

Никаких сборщиков, npm и зависимостей — три файла, работают из коробки.
