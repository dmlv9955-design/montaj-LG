Отчёт монтажника + Фотофиксация
Этот проект использует современный подход к разработке: локальная работа в VS Code с автоматической синхронизацией на GitHub и в Google Apps Script.

СТРУКТУРА ПРОЕКТА
Проект разделен на две части, которые лежат в одной папке:

Фронтенд (Корень проекта)
Файлы: index.html, photos.html, script.js, photos.js, style.css.
Куда идут: GitHub (хостинг сайта).

Бэкенд (Папка backend)
Файлы: Code.gs, photos.gs, coords.gs, appsscript.json.
Куда идут: Google Apps Script (синхронизация через утилиту clasp).

ПЕРВОНАЧАЛЬНАЯ НАСТРОЙКА (если нужно развернуть с нуля)
Шаг 1. Node.js и clasp
Установите Node.js с официального сайта. Затем выполните в терминале VS Code команду:
npm install -g @google/clasp

Шаг 2. Авторизация
Введите в терминале команду и разрешите доступ в браузере:
clasp login

Шаг 3. Включение API
Перейдите на страницу script.google.com/home/usersettings и включите Google Apps Script API.

Шаг 4. Установка Git
Скачайте и установите Git с официального сайта.

Шаг 5. Настройка привязки clasp
В корне проекта создайте файл .clasp.json со следующим содержимым (замените ВАШ_SCRIPT_ID на реальный ID из настроек скрипта):
{ "scriptId": "ВАШ_SCRIPT_ID", "rootDir": "./backend" }

Шаг 6. Защита от лишних файлов
В корне проекта создайте файл .claspignore, чтобы clasp не отправлял в Google файлы сайта. Впишите туда:
/
!appsscript.json
!*.gs

ЕЖЕДНЕВНЫЙ РАБОЧИЙ ПРОЦЕСС

Изменение серверного кода (Google Apps Script)
Если вы поменяли Code.gs, photos.gs или coords.gs:

Сохраните файл в VS Code (Ctrl+S).

В терминале VS Code выполните: clasp push

КРИТИЧЕСКИ ВАЖНО: Зайдите в браузере в ваш проект Google Apps Script, нажмите Развернуть -> Управление развертываниями -> (Карандаш) -> Версия: Новая версия -> Развернуть. Без этого сайт не увидит изменения!

Изменение кода сайта или синхронизация
Если вы поменяли photos.js, style.css и т.д.:

Сохраните файлы в VS Code.

В терминале выполните по очереди:
git add .
git commit -m "Краткое описание изменений"
git push
Это обновит сайт на GitHub Pages.

Скачивание изменений из Google
Если вы что-то правили прямо в браузере (не рекомендуется, но бывает), выполните:
clasp pull

ИНТЕГРАЦИЯ С ИИ
Если вы хотите, чтобы ИИ-ассистент (например, Cline или Cursor) сам менял код и делал clasp push, настройте MCP-сервер gas-clasp-mcp.
